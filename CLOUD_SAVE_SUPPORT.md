# Cloud Save+ Support

Need help with Cloud Save+? This page provides basic support information for the iOS app.

## Common help

### Backup and storage
- Free accounts include 1 GB of cloud storage.
- Cloud Save+ plans provide 500 GB, 1 TB, or 2 TB of storage.
- Manual and automatic backup are available on the Free plan.

### Sharing and receiving files
File sharing and receiving are available on Cloud Save+ paid plans.

### Subscriptions
Cloud Save+ subscriptions are managed through your Apple Account. You can view, manage, or cancel an active subscription from iOS Settings under your Apple Account subscriptions.

If you cancel, paid access remains available until the end of the current billing period. Existing files are not automatically deleted when a subscription ends.

### Restore purchases
If you have an active Cloud Save+ subscription but the app does not show your paid plan, open the Cloud Save+ subscription screen and use **Restore Purchases**.

## Contact support
For support, bug reports, or account-related questions, please open an issue in this GitHub repository:

https://github.com/osagiejoshua1/osagie_joshua/issues

When reporting a problem, please include the app version, iOS version, and a short description of what happened. Do not include passwords, private keys, payment information, or other sensitive information.
